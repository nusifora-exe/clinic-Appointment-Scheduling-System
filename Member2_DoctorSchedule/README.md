# Doctor Schedule Management System

**Project:** Clinic Appointment Scheduling System  
**Module:** Doctor Schedule Management  
**Team Member:** Member 2  
**Programming Language:** C

## Project Overview
This module manages doctor schedules and availability information. It allows users to add doctor schedules, view existing schedules, and update available times.

## Features
1. **Set Doctor Schedules** – Add a doctor's name, specialization, and available time.
2. **View Doctor Schedules** – Display saved doctor schedule information.
3. **Manage Available Time Slots** – Update a doctor's available time.
4. **File Handling** – Store and retrieve doctor schedule data using a file.

## Technologies Used
- C Programming Language
- File Handling
- Structures
- Functions

## How to Run

Compile the program:

```bash
gcc doctor_schedule.c -o doctor_schedule.exe
```

Run the program:

```bash
.\doctor_schedule.exe
```

## Data Storage
Doctor schedule information is stored in `doctor_schedule.dat`.
